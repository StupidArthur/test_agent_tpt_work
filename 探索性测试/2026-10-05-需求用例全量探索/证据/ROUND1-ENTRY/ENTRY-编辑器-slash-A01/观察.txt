技能
配置连接器
configure-connector
从市场下载连接器，按用户要求配置、测试连接，保存并应用。当用户想配置或接入市场中的某个连接器时使用，例如「配置连接器」「接入市场里的 xxx」「把 xxx 连上」「下载 xxx 连接器」。
添加连接器
create-connector
引导用户在对话中添加 MCP 连接器。当用户想粘贴 mcpServers JSON 或描述连接信息（名称、地址、认证）来添加连接器时使用，例如「添加连接器」「导入连接器」「接入这个 MCP 服务」。
创建技能
create-skill
引导用户在 DSH 中一步步创建新技能。当用户想要创建、编写、制作或保存一个新技能，或询问技能结构、最佳实践或 DSH 的 SKILL.md 格式时使用。
diagnose-windows-sandbox-acl
Use on Windows for unexpected DSH sandbox access denials: workspace writes or listing fail, or an ordinarily readable path cannot be read. The bundled script inspects the path and every ancestor, reports observations and action reasons, and supports scoped, backed-up ACL repairs. Expected confinement denials need no ACL repair.
Agent 创建与修改
expert-manager
在 TPT 桌面端新建或修改 Agent：收集信息 → 在数据根里初始化包 → 写 metadata.json 与 agent.md（可带内嵌 Skill）→ 校验 → 注册（写 .registry.json）→ 收尾。触发词：新建 Agent、创建 Agent、生成 Agent、做一个专家、把资料转成 Agent；修改 Agent、编辑 Agent、更新 Agent、改提示词、改简介、改标签；批量创建 Agent。
查找技能
find-skills
在 DSH 内查找、浏览和安装技能。不要当作例行第一步使用。仅当用户显式要求从技能市场查找、浏览或安装技能，或本地没有已安装技能能覆盖任务且大概率需要专用技能时使用。搜索范围为本机已安装技能与技能管理插件提供的技能市场目录。
指标数据查询
indicator-data-query
按指标名称查询 supOS 指标服务的指标数据——技能自带脚本先按名称取指标详情拿到指标编码，再按编码查询指标数据（实测 MEA/目标 TAR/平衡 BAL/当量 EQU，小时/分钟/日/月/年单点与区间），并在本地汇总（数据点数、最小/最大/均值、quality 值类分布）。当用户查指标值、实测值、目标值、能耗或产量指标，或按日期范围取指标数据时触发。
指标信息查询
indicator-info-query
按指标名称查询 supOS 指标服务的指标信息——指标清单（指标 ID 与名称）与指标详情（指标编码、类型、单位、计算精度、物料、实测/平衡/当量/目标值公式与取值方式、启用状态、创建信息）。当用户问有哪些指标/指标清单/指标编码/指标单位/指标类型/指标公式/指标启用状态，或取数前需要确认准确的指标名称时触发。
office-docx
Create, read, edit, and check Word documents (.docx), including reports, letters, and formatted tables. Use when a DOCX file is an input or requested deliverable. Load this skill before running Office commands. Use only bundled LibreOffice unless the user explicitly opts out; without that opt-out, do not search for another LibreOffice executable.
office-pptx
Create, read, edit, and check PowerPoint presentations (.pptx), including slide text, tables, images, and charts. Use when a PPTX file is an input or requested deliverable. Load this skill before running Office commands. Use only bundled LibreOffice unless the user explicitly opts out; without that opt-out, do not search for another LibreOffice executable.
office-xlsx
Read, create, and modify Excel workbooks (.xlsx), including data, formulas, formatting, and pandas analysis. Use for Excel inputs or deliverables. Load before running Office commands. Data and formula tasks skip visual inspection; inspect only for formatting or layout needs. Use only bundled LibreOffice unless the user explicitly opts out; without that opt-out, do not search for another LibreOffice executable.
