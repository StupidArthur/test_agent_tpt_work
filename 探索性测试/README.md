## 审核后入库

1. 记录原始观察、前置条件、证据、未知项和拟入库位置，默认状态为“待审核”。
2. 由用户或指定审核者审阅；复现成功不等于审核通过，Agent 不自行批准自己的产出。
3. 审核结果可以是通过、需补证、驳回或部分通过；保留审核者、日期、意见和具体批准范围。
4. 仅将获批内容合并到正式产品资料、缺陷库或测试方法目录，注明来源与审核依据；原始批次记录继续保留。

用户明确要求直接修改正式规范时，按该次授权范围执行。新增探索结论仍需审核。
