## 本机实际试用与修正

- 原版独立调用：记忆库/日志/概览、高级设置、编辑弹窗可读取。`mem.setAdvanced` 实际抛 `ReferenceError: D is not defined`。
- 原版连续调用：`inspectSurfaces` 关闭共享连接，下一函数报 `Target page, context or browser has been closed`。修正为释放函数自身的连接句柄，连续两次读取及后续页签/参数读取成功。
- 原版 inspectSurfaces 读到了侧栏和会话文字。修正为设置弹窗限定范围；缺失指定范围抛错，去掉 body 回退和吞掉读取异常的空值。
- 读取：三个页签、记忆库行、高级视图、编辑视图、14 项高级参数、实际文件内容/字节/SHA-256。主库最终函数名也重新实际调用，不以静态导入替代。
- 写入：添加本轮唯一事实标记，确认匹配列表行恰为 1 且 MEMORY.md 有对应内容；按文件名和初始哈希编辑该条目，独立回读文件与请求一致。
- 恢复：MEMORY.md 与 index.json 按本轮备份恢复后 SHA-256 与初始一致，清除本轮新建备份文件；保留 audit 增量，原审计内容前缀不变。每次结果记录 actual/expected 和恢复情况。写入实测对象为 MEMORY.md，不代表其他层全部写入行为已复测。
- 负向调用：删除首条探针不再登记；越界相对路径拒绝；错误的编辑初始哈希拒绝，均在实际操作前止步。

原尝试不覆盖删除。`原版试用/` 留返回结果，完整先后轨迹在 `运行日志/业务调用.jsonl` 和 `审核/函数调用/`；修正版准备时一次因参数 schema 尚未更新而中止，保留在 `修正版试用-准备缺口.json`，修复后续试用另写时间戳文件。
