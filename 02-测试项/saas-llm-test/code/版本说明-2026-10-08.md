# LLM网关测试版本：2026.10.08-r1

本版范围：持续容量执行、证据治理、判定与报告。真实网关新请求：0；历史原始测量不改。

## 改进

- 每个窗口调用创建独立attempt，开始/结束与请求发起证据分开；中断资源日志逐行刷新，不覆盖旧轮。
- 显式续跑核验SHA、冻结配置与代码版本、时长、样本及排空；不按“文件存在”跳过。
- 压力期间采样CPU/RSS/线程/句柄/TCP，采样失败影响有效性。不是精确峰值或服务端指标。
- CAP-04按每个有效窗口汇总3/5/10秒；至少两有效窗，实验无效不充当首失败档，非单调不给可靠容量。
- 短请求网关成功与marker内容质量分开；主失败类别互斥。容量E2E采用全部已完成尝试耗时，历史条件分布仍保留并注明。
- 正式窗口登记credential_id与其他同网关调用；默认unknown不宣称独占容量。声明exclusive需要执行者实际安排暂停，不是系统证明。
- 正式结果入口同步Task A已审核60/85/100下界、10秒上限未知；保留原初筛与Task B观察。

## 使用

按code/README与执行规范选择已分配任务，CAP-04补齐credential_id/load_isolation。压力采样需psutil；缺依赖或访问失败保留未验证。旧单SLO输出兼容，新增capacity_3way；不把轻量工具负载当标准Agent。

未自动增加新的真实压测、Open Arrival专项或服务端监控；未实现后台自动重启。剩余10秒边界实测要在独立授权任务中执行。
