整合既往沙箱探索、四权限档验证、提权审批和 Windows ACL 记录，形成统一测试项。本次整理不操作软件、不复测、不改变历史缺陷状态。

1. [测试设计](测试设计.md)：对象、分层范围、16 个检查项、断言和恢复。
2. [历史记录与证据](历史记录与证据.md)：已有结果、S-01～S-12 的归属、未验证项和原报告入口。
3. [来源清单](来源清单.json)：引用材料及证据的路径、SHA-256 和检查项归属。

执行时另外读取本轮任务 README、[测试技能](../../03-测试技能/exploratory-testing/SKILL.md) 和 [软件 UI 操作工具](../../04-测试工具/ui-operations/README.md)。本测试项是长期范围，不等于已经分配了 16 条执行任务。

## 先分清对象

| 维度 | 历史资料中的取值 |
|---|---|
| 用户可见的权限选择 | 仅可查看、工作区内修改、完全权限、Auto review |
| 底层沙箱实现 | acl、elevated |
| 一次操作的审批 | 允许一次、拒绝、请求更宽权限 |

三者分别验证。切到完全权限不表示已启用 elevated；出现审批也不证明命令已执行或磁盘已改变。
