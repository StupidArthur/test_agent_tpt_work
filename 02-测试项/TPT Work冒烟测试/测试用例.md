# TPT Work 冒烟测试用例

来源：用户口述并已判定的smoketest-1012；保留全部15个编号（含3个R对照轮），不重新评判LLM回答质量。历史结果见[用户确认结果](smoketest-1012-用户确认结果.md)，下一轮单独记录实际结果。

原文中的用户名、盘符、目录、PID、版本、时间和凭据描述均为历史样本，执行前替换成本轮授权对象；登录使用[测试账号.json](测试账号.json)中的固定测试账号；不能清空历史目录或直接使用原PID。SMK-04R/05R/12R是对照场景，不覆盖原编号。

> **运行前置（重要）：本用例要求在一个“全新环境”（初始/首次安装状态）下执行。** 机器上若保留历史数据（会话/项目/登录态），依赖“登录页 / 无项目 / 无会话”的用例（尤其 SMK-01、SMK-05 等）前置不成立，**不得判通过**。
>
> 如何把 TPT Work 恢复到初始环境：关闭应用 → 移走/删除 `%USERPROFILE%\.tpt-work` 与 `%APPDATA%\tpt-work` → 以 `--remote-debugging-port=9234` 重开 → 核验（登录页、用户名/密码为空、`暂无项目`、`暂无任务`）。方法与边界见 [reset-environment-to-initial-skill](../../03-测试技能/reset-environment-to-initial-skill/SKILL.md)。
