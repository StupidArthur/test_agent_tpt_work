# 从测试项分派到执行任务

本页供管理者分派任务使用；执行者从本轮 README 和 [测试技能](../03-测试技能/exploratory-testing/SKILL.md) 开始。

## 分派前明确

- 本轮目标、测试项来源、完整编号与必要断言；按共享场景组织，通常每批约 10～20 条，不拆断前置链。已分配长任务仍执行原完整队列。
- 负责 PC、UI/API 通道、环境核验、样本、授权边界和恢复办法。若需启动或接入 TPT Work，按 [TPT Work 接入技能](../03-测试技能/tpt-work-access/SKILL.md) 分派对应通道；测试方法仍按通用技能执行。各 PC 使用本轮唯一身份，不硬编码历史盘符或复制其他机器读值。
- 输出任务目录、完成标准与交付方式。用 [任务模板](../05-探索性测试/_模板-通用测试任务/README.md) 创建入口。常规测试、复测和用例试运行分派前填好用例；探索发现可由执行者生成检查点。

历史覆盖由管理者核对。原先测过的内容不静默删除；拟删项需列理由和影响，经用户明确确认。暂时无入口或缺条件只影响本轮状态。执行者发现遗漏登记待审，不自行把全部历史扩进本轮队列。

## 交付与审核

结果、证据、日志、任务函数和恢复情况均留本轮目录。使用现有记录格式，字段语义见 [记录契约](../03-测试技能/exploratory-testing/references/records.md)，不为凑目录创建空文件或另建框架。队列只有一份权威来源，文件名不限。

管理者分别审核业务结论与工具复用：实际值是否支持断言，新增函数是真缺能力还是已有工具没找到。获批内容再入正式资料或主库；原始结果与代码保留。交付附分支/commit（适用时），不同 PC 不混作一次实测。
