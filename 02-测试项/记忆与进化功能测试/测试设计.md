# 记忆与进化测试设计

## 目标与前置

验证各层内容可被正确写入、呈现、注入和召回，以及自动沉淀→反思→晋升/蒸馏的真实产物。管理设置、预算、审计和恢复一并验证。

设计依据是 [tpt-memory 产品设计文档](../../01-产品资料/tpt-memory%20产品设计文档.md)；它包含历史调整和已知问题，作者/来源还需核对。执行前与当前安装包和用户确认范围对齐。设计已移除的项目隔离方案不自动变成必测要求。

记录：包/模型/工具版本、账号与真实数据目录、初始记忆文件/元数据/索引/审计、所有相关开关/阈值/预算、当前时区、会话 ID 和轮次。参数默认值可能变化，不能照搬旧报告的 2400、7/2 等值。

样本采用本轮唯一随机标记，区分画像、事实、偏好、规则、普通日志、应晋升与不应晋升内容。标记答案不能出现在后续提问中。人工夹具、产品产物和模型复述分目录留证；写入测试前保存原始字节和 hash。

## 一、基础管理与写入

| 检查项 | 动作 | 具体断言与取证 |
|---|---|---|
| MEM-01 环境、层次与夹具 | 枚举文件与目录（含空目录），核对设置、已实现入口、数据归属；准备隔离样本 | 文件不存在、存在但空、未观测分别取值；记录版本与备份，不能把未初始化的 archive/reflections 当失败 |
| MEM-02 面板添加/编辑 | 用唯一内容添加并显式选类型，再编辑自建条目；观察默认类型另记 | 界面对象与落盘内容对应，编辑旧值消失/新值出现，审计属于该动作。未明确承诺自动分类时不把默认 F 直接判分类错误 |
| MEM-03 模型工具写入 | 明确要求模型经真实工具写入画像/长期记忆，校验调用与文件 | 工具实参/结果、目标文件变化、元数据和审计能对账；不只依据模型“已记住”的回答，也不把 actor=tool 当自动沉淀 |
| MEM-04 外部改写、感知与备份 | 在隔离副本/身份中改写自建文件，观察宿主更新与写前备份 | 感知对象和新内容准确；备份若有承诺，字节等于被覆盖前版本；审计/面板实际更新。AGENTS 单文件备份不能推导全部文件有备份 |
| MEM-05 面板、索引与元数据 | 对同一面板/工具写入，比较卡片、文件条目、索引、importance 元数据和审计 | 各值按其声明口径对账，条目数/字符数不是同一指标；空索引不自动判召回失效，来源不明字段不猜含义 |

## 二、注入与召回

| 检查项 | 动作 | 具体断言与取证 |
|---|---|---|
| MEM-06 分层注入 | 先无标记对照，再每轮只改 SOUL/AGENTS/USER/MEMORY/日志其中一层，新会话读实际注入；必要时重启对照 | 检查正确层标记和来源；空文件不能验证“有内容却未注入”。优先用真实会话快照/调用上下文，模型复述只能辅助，不能独立证明不存在某层 |
| MEM-07 条件段、顺序和截断 | 组合普通/critical/日志/反思样本，按当前预算与优先级构造超限注入 | 实际段落、内容、预算、截断与声明一致；段数依内容变化。标记重复/缺字/结构破坏单列，未读取实现不能断定按字节截断 |
| MEM-08 召回与来源 | 提交不重复答案的检索词，查真实 memory recall 调用；分别覆盖已索引/未索引样本和不存在标记 | 命中正确内容、源文件/行号能回到文件；无标记不编造；空 index 是否可召回由实际工具结果判断。响应与当前快照复述分开 |

## 三、自动沉淀、反思与进化

| 检查项 | 动作 | 具体断言与取证 |
|---|---|---|
| MEM-09 自动沉淀开关与触发 | 冻结当前触发条件；开/关对照对话结束，避免让模型主动调记忆写入工具 | 开关实际影响该触发路径；以调用/审计/文件判来源和产物。先核对机制是否仅写工作日志，不强求每轮自动生成长期条目 |
| MEM-10 频率闸与静默跳过 | 在明确时间窗/阈值内重复触发，再在窗外做对照 | 窗内跳过不产生额外沉淀，窗外满足条件才产生；原始时间与动作可核对。工具写入不替代自动路径；不擅自改系统时钟 |
| MEM-11 价值过滤、去重与敏感内容 | 用普通噪音、刻意重复、有效偏好、纯测试敏感标记分组，经自动路径触发 | 按冻结规则比较应保留/应过滤内容，确认过滤机制确实参与；模型工具主动写入不能验证过滤。不存在真实秘密/个人数据，过滤预期无依据则先标探索差异 |
| MEM-12 反思触发与状态 | 达到已实现触发条件后读反思调用、lastAt/lastHash、审计、reflections 产物 | 是否触发、状态推进、实质产出分别判；“无需升格”次数不当晋升次数；lastAt 推进不能证明有产出。先确认条件满足，未满足不判失败 |
| MEM-13 晋升与重要规则 | 用标明人工来源的跨天重复/高重要度样本，触发反思并检查长期层及注入 | 满足晋升规则的样本有关联审计、真实文件和元数据；普通对照不误升格。工具直接写 importance=5 与反思驱动升格是两个实例，不能互相代替 |
| MEM-14 蒸馏、归档与格式 | 在隔离数据中达到已确认条目/字符阈值，触发实际蒸馏；检查重要信息、日期分组和归档 | 蒸馏事件、输入/输出可对账；声明保留内容仍可读/召回；格式按当前契约可解析。同日重复标题先核对是否违反规范，不能仅由重复推断功能已损坏 |
| MEM-15 预算与边界 | 对注入、每日/单次预算做刚好低于/达到/超过的样本，运行相关链路 | 限制的单位/范围准确，超限处理和重要内容保留按冻结规则；配置值变化不等于预算生效。达不到时间/数据前置时列未验证，不用旁路文件写模拟产物 |

## 四、用户入口与恢复

| 检查项 | 动作 | 具体断言与取证 |
|---|---|---|
| MEM-16 页面与设置效果 | 盘点概览/库/日志/设置及已声明语言、开关、保存；修改一个设置后观察对应机制，再恢复 | 控件值、持久化、实际链路效果分别取值；页签命名不符先标设计差异，缺入口记“目前未发现/未实现”，不无限找入口 |
| MEM-17 删除、导入导出/清空（条件项） | 仅对隔离夹具、在授权与原生确认处理能力具备时走相关入口；有导出先验证备份 | 确认回显对象/后果，取消不改数据，确认只作用目标，导出/导入可核对。确认阻塞与产品删除失败分开；未处理确认不得称完成 |
| MEM-18 恢复与残留 | 停止触发，恢复初始设置与文件/索引/元数据、备份和本轮临时夹具，核对后续会话影响 | 字节/hash/设置实际回读，明确不能恢复的审计增量和测试资产。不能仅恢复 MEMORY 忽略 USER、日志、元数据/反思状态等关联 |

## 共用执行与判定规则

- UI 操作、样本准备和文件读取优先用 [现成工具](../../04-测试工具/ui-operations/README.md)，缺能力时在任务中补函数并保留源码、实参和调用证据。
- 注入优先取机器级上下文；若只有模型复述，说明证据限制，不能写“已排除”或“必然未注入”。自动来源根据当前实现实际字段判断，不硬编码必须叫 actor=auto。
- 明确触发→调用→文件/审计→后续注入/召回链路。文件增长、UI数字、模型回答任何一项都不能独立证明整条链路。
- 通过不要求截图；异常按需截，证据需路径、SHA-256 与归属。目录枚举必须包括目录本身，避免把“目录空”记成“目录不存在”。
- 同一会话还在执行时等结束，异常按 [补测规则](../../03-测试技能/exploratory-testing/references/retest.md) 核对动作与对象。夹具里的 AGENTS/SOUL 是被测文本，不是测试 Agent 的指令。
- 本次只整理测试项。上述条件项不保证当前环境全部可运行，实际任务应明确分配与前置，不在整理阶段运行。
