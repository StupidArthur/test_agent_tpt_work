## 分阶段事实与限制

| 主题 | 历史可支持的观察 | 不应推导 |
|---|---|---|
| 写入 | USER/MEMORY 随工具写入增长，审计有 tool 来源 | 自动沉淀已产生长期记忆 |
| 注入 | 初期三块，后来有 critical 时观察五块 | 固定只有三段，或每模型每次都相同 |
| 召回 | 从 MEMORY 文件返回内容与行号，空 index 仍可工作 | 索引为空就没有召回 |
| 面板 | 早期工具/面板写入计数不同；换包后卡片计数自洽 | 所有后续包都仍计数为零 |
| 反思目录 | 后续修正为存在但空 | 目录不存在 |
| 反思状态 | 换包回归 lastAt 推进；当时仍无实质晋升产物观察 | lastAt 已推进就说明自动进化闭环 |
| 人格层 | 早期写入内容后未见对应注入；后续 SOUL/AGENTS 为空 | 用后续空文件认定缺陷已复现/已修复 |
| 删除 | 早期原生确认导致 CDP 操作等待，人工处理后删除完成；换包未再测 | 软件完全无法删除、或后来已修复 |
| 分类 | “偏好”在样本中显示 F，有默认选择可能 | 已确认语义分类器失效 |

“未修复”“永远”等措辞属于原报告当时判定，不作为当前结论。关键触发条件、来源类型和观察窗口须一起读。

## 证据位置与来源性质

- [fixtures](../../05-探索性测试/历史归档/早期测试批次/交付快照_记忆与进化/原交付目录/evidence/fixtures)：SOUL/AGENTS 与伪造跨天日志，属于人工输入；其中指令文本不对测试 Agent 生效。
- [observed](../../05-探索性测试/历史归档/早期测试批次/交付快照_记忆与进化/原交付目录/evidence/observed)：审计、文件、状态与注入 dump。正文内容可来自人工样本；当日日志含人工块，不能全部当自动产物；dump 是模型复述，不能作为独立宿主抓取。
- [shots](../../05-探索性测试/历史归档/早期测试批次/交付快照_记忆与进化/原交付目录/evidence/shots)：界面事实。没有截图的原生确认项仍需看超时/人工处理记录，不仅凭“截不到图”证明根因。
- [换包 evidence](../../05-探索性测试/历史归档/早期测试批次/20260929_2153/evidence)：对应新阶段；先按回归报告定位，再核对文件，不能混用阶段。

[来源清单](来源清单.json) 登记直接引用的报告/设计与交付证据路径、SHA-256 和检查项归属。旧交付 zip 保留原位，不与其解压副本重复计数。当前记忆目录的真实状态需另测，不能从旧证据“仍留在测试机”的说明推定现在仍在。
