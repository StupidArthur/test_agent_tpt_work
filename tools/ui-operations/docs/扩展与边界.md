# 找不到工具时：补充与审核

[返回工具入口](../README.md)

## 先确认是缺函数还是选错

按当前 case 执行 `--plan`，按业务词和 namespace 执行 `--list`，对候选函数 `--describe`。核对它是否会额外新建会话、自动恢复、导航或读错对象。部分判据只需要换读取函数或正确绑定返回值，不需要另写点击脚本。

## 确实缺少时，写任务函数并保留

业务函数放 `探索性测试/<任务>/code/business/`；共享接入和控件定位放 `code/automation/`。业务函数签名 `async (ctx,args)`，复用主库接入与 `ctx.recorder.action/read`；保留真实动作、读取和异常。

在本任务 `code/business/catalog.json` 登记，例如：

```json
{
  "functions": [{
    "name": "task.readCustomPanel",
    "file": "code/business/custom.mjs",
    "export": "readCustomPanel",
    "parameters": {
      "type": "object",
      "properties": {},
      "required": [],
      "additionalProperties": false
    }
  }]
}
```

函数需要返回自身实际读取，不是预设成功值。上述登记只是结构示例，文件和导出实现存在后才能调用：

```powershell
node tools/ui-operations/call.mjs --describe task.readCustomPanel --task "探索性测试/本轮任务"
node tools/ui-operations/call.mjs task.readCustomPanel --task "探索性测试/本轮任务" --args-file "参数.json"
```

名称不能覆盖主库，文件必须位于本任务 code 下。自动保留本任务代码快照。在 `新增函数清单.json` 写：case、缺口、函数路径、参数、真实调用证据、恢复办法。临时探针也必须留存，不能测完丢弃。

任务结束再审核跨机器参数、对象绑定、等待、断言读取、异常和恢复，决定如何并入主库；并入后保留任务来源。不会要求 Agent 为每条 case 都新增函数。

- 当前任务权限函数已补齐并实测。
- 仍缺按准确 URL 关闭测试浏览器页面并核验的主库函数。
- CDP 合成按键无响应不能排除原生快捷键机制；页面内没有变化不能排除帮助打开外部窗口。相关结论需要其他观测，不得直接认定缺陷。
