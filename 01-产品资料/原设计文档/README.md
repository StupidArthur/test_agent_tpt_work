# 原设计文档

用户于 2026-10-05 提供 external 中的设计资料，并明确要求收入产品知识。本目录保存原始导出文件，正文、文件名和来源元数据保持原样；external 中的源文件也保留。

共收录 **31 份分篇文档及 2 份合并版文件**。两份合并版 SHA-256 相同，属于同一份内容的重复副本；保留原路径，并在来源清单中登记。

## 使用约定

- 这些资料是设计依据，不能单凭文档内容认定当前安装包已实现相关功能。
- 文档的版本、草稿、待评审和会议纪要标记沿用原文；出现冲突时核对版本与评审结论，不自行假定所有材料均已批准。
- 导出中部分附件、原型、图片或表格仅保留占位文字；本次只收录 external 中实际存在的文件，没有补取原站附件。
- 后续从探索测试得到的解读、实现差异和疑似缺陷，先进入根目录的探索性测试待审核区，审核后再入正式知识库。
