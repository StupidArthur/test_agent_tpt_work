3.1 F015 标记为未读

原表备注： 任务状态见补充文档。

本条所述任务状态，是指左侧栏任务条目显示的状态。任务状态包括：

运行中；

完成；

等待用户；

执行失败。

“等待用户”指任务因缺少信息、能力连接或动作审批，必须等待用户操作后才能继续相关步骤。用户主动终止任务属于用户行为，终止结果在任务详情中记录，左侧栏不显示对应的任务状态标记。

左侧栏的“完成”标记同时承担未读提醒作用，不再设置与其并列的独立未读标记。任务完成时，按照以下规则展示：

用户正在当前任务详情页时，页面直接呈现任务完成结果，左侧栏对应任务条目不显示完成标记；

用户不在当前任务详情页时，任务完成后在左侧栏对应任务条目显示完成标记，提醒用户返回查看结果；

用户进入该任务并查看完成结果后，完成标记消失；

用户主动将任务标记为未读时，复用同一个完成标记，提醒用户稍后返回查看。

用户主动终止任务时已经位于任务详情页并查看了当前内容，因此左侧栏不显示完成或未读标记。

状态标记的颜色、图形、动效和位置由原型及 UI 设计统一定义，本文不作视觉限定。

3.2 F034 添加资料

添加入口与资料范围

用户可以通过输入区的 @ 或 + 添加本地文件，也可以从“数据资产 · 我的文件”中选择已有资料。

@ 提供“添加本地文件”和“我的文件”两个资料入口；

+ 除上述资料入口外，还承载 Agent、技能和连接器等任务能力；

本地文件以本地路径引用方式添加，“我的文件”以数据资产记录引用方式添加；

支持一次选择多个文件；

当前一轮待发送内容最多添加 30 个附件；

文件夹不作为输入框附件添加。项目关联的本地文件夹通过项目工作区使用，不按附件处理。

添加资料时不上传、读取或解析文件内容，不限制文件格式和大小。文件能否访问、读取和解析，在任务发送后的执行过程中判断并反馈。

输入附件分类与图标映射矩阵

本地文件不限制添加格式。下表仅用于确定常见文件在输入框中的分类、展示形式和图标，不作为文件可添加范围或 Agent 可解析能力的判断依据。

系统能够获取适用的文件类型图标时可以直接使用；无法获取或需要保持产品视觉一致时，按照下表匹配产品图标。未被单独识别的格式统一使用通用文件图标。

[table]

文件选择器展示所有文件，不按照文件格式过滤。同一文件类型在输入附件和独立文件产物中原则上使用一致的基础图标；独立产物的具体展示规则以 3.7 F061 为准。

输入框中的附件展示

附件位于输入文字上方，与文字共同组成本轮待发送内容。

用户选择本地文件后，输入区立即生成附件，不展示上传或添加进度；

图片展示缩略图和文件名，点击后进入整屏预览；

其他文件展示文件卡片，包含文件名、文件格式和对应类型图标；

文件名过长时省略显示，悬浮后展示完整名称；

多个附件按照添加顺序排列，超过输入框可见范围后支持滚动查看；

附件区域显示当前数量和上限，例如“附件 12/30”；

发送前可以单独移除任一附件；

存在两个及以上附件时，附件区域提供“清空”操作；

移除或清空附件只影响当前输入区，不删除本地原文件，也不影响“我的文件”中的已有资料。

文件类型图标仅用于帮助用户识别附件类别，不表示 Agent 已经读取或理解文件内容。

添加情况与数量边界

添加资料阶段只处理正常添加、重复添加、数量超限和清空附件四类情况。

[table]

数量限制按照当前一轮待发送内容计算，不限制整条对话历史中曾经使用过的文件总数。

用户一次选择的文件数量超过当前剩余名额时，不由系统自行截取部分文件。例如当前已有 20 个附件、用户新选择 15 个文件时，本次选择的 15 个文件均不添加，并提示当前还可添加 10 个。

清空操作不使用大型确认弹窗。用户误操作时，可以通过顶部提示中的“撤销”恢复全部附件；如果一期暂不支持撤销，则点击“清空”后使用轻量确认提示，由用户确认是否清空当前全部附件。

发送后的附件去向

用户发送任务后，附件与本轮用户消息一起固定展示：

附件区域位于用户文字上方；

图片保留缩略图，其他文件保留文件卡片；

发送后的附件不能从历史消息中直接移除；

点击附件后，按照对应文件类型打开预览；不支持产品内预览时，提供适用的外部打开操作；

文件的访问、读取、解析、解码和内容处理发生在任务执行过程中。文件无法访问、无法解析、受密码保护、仅能处理部分内容或执行环境资源不足等情况，按照任务过程中的工具调用和异常恢复规则反馈，不属于附件添加异常。

输入附件的分类与图标映射以本节为准；发送后的文件预览能力以 F074 文件类型能力矩阵为准。

3.3 F047 呈现过程说明

设计目标

过程说明用于让 Agent 主动向用户说明当前判断、任务进展、遇到的问题或下一步行动，帮助用户理解任务正在如何推进。它不是执行记录，也不展示详细推理过程。

设计实现要求

过程说明以黑色自然语言正文展示，使用简短、自然且面向用户的语言，不展示命令、JSON、底层工具名称或详细推理过程；

不要求每个执行动作前后都生成过程说明，仅在有助于用户理解任务进展时出现；

过程说明不承担执行记录功能，不用于罗列 Agent 已完成的每一项具体操作；

过程说明不需要单独使用卡片或图标，应与执行记录保持清晰的视觉层级差异；

任务完成、中止或失败后，过程说明随本轮过程区统一折叠，用户可通过过程入口重新展开查看。

3.4 F048 呈现进行中状态

设计目标

进行中状态用于表达 Agent 当前正在做什么，让用户知道任务仍在推进。它只表示当前状态，不承担历史记录功能。

设计实现要求

展示当前状态标识和简短动作文字；任务级状态可表达“正在思考”，动作级状态可表达“正在获取页面”“正在运行测试”等；

状态文字使用灰色，通过闪烁、呼吸等轻量动态表达仍在进行；

当前动作发生变化时，原位置及时更新为新的动作文字；

当前动作完成后，进行中状态消失，不继续占用主过程区；

只有需要保留供用户回看的已完成动作，才转为 F049 执行记录；

任务结束后，不保留仍在进行中的状态。

3.5 F049 呈现可展开执行记录

设计目标

执行记录用于说明 Agent 实际执行过的操作，并允许用户按需查看更详细的信息。运行命令、搜索网页、使用浏览器、读取或修改文件、调用外部应用或业务能力等动作，均可形成可回看的执行记录。

设计实现要求

主过程区默认仅展示“操作或对象标识 + 用户可理解的动作摘要”，例如“已运行测试”“已搜索网页”“已读取文件”“已创建 prototype.html”或“已在 Notion 中搜索”。底层工具名称、完整参数和原始输出不直接铺在主过程区。

设计需覆盖以下四种展示状态：

单条执行记录：默认收起，仅展示单个动作的图标和摘要；

聚合执行记录：连续同类动作合并展示，例如“运行了多个命令”；

子记录：展开聚合记录后，展示其中包含的多个具体动作；

执行详情：继续展开某一动作后，查看命令、输出、结构化结果或错误等详细信息。

3.7 F047–F050 共用的过程区边界

同一轮中的过程说明、进行中状态和执行记录，按照实际发生顺序穿插在同一过程区；

任务运行中默认展示必要的过程说明、当前状态和低干扰执行记录，不默认展开技术细节；

任务完成、中止或失败后，过程区统一收束为“耗时 X 秒”等过程入口；展开后恢复本轮完整过程，但不混入最终答复、独立产物或文件变更审查；

等待用户补充信息、连接能力或批准高风险动作时，沿用对应的用户介入卡片，不降级为普通执行记录；

阻止任务继续推进的错误使用异常状态呈现，不降级为普通执行记录。

设计备注： 本文明确必须呈现的内容、状态变化和交互层级。除 F047 使用黑色自然语言正文，以及 F048、F050 的进行中或等待文字使用灰色动态反馈外，具体色值、图标样式、卡片样式、间距和动效方案由 UI 设计在原型中统一定义。上述“待补图”位置在对应原型完成后补充截图和图注。

3.8 F061 交付多类型结果与产物

独立产物的收录条件

独立产物必须同时满足以下条件：

具有独立资源身份，例如文件、网页、图像或图表；

用户可以在任务结束后再次打开、预览、编辑或使用；

Agent 在最终答复或任务交付中明确将其作为成果交付。

普通答复文本、代码块、临时脚本、中间数据、日志、错误信息，以及未被明确交付的普通文件修改，不作为独立产物。文件变更由文件变更审查功能另行呈现，不自动成为独立产物。

最终答复中的内嵌结果

最终答复中直接渲染的表格、结构化数据、图表或图示，如果没有对应的独立资源记录，属于答复内嵌结果，不作为独立产物，也不进入置顶摘要的“输出内容”。用户可以直接查看和复制；需要在对话外继续使用时，可以将其下载为文件。

[table]

内嵌结果不需要同时展示全部操作。复制作为基础操作常驻或在悬浮时显示；复杂表格、较大的结构化数据、图表和图示提供放大或整屏查看；下载及格式选择收纳在“更多”中，并预先选中默认格式，用户不必每次先选择格式。

“下载”用于将当前尚未形成文件的内嵌内容转换为文件并保存到本地；“另存为”用于将已经存在的独立文件保存到其他位置、使用其他名称或转换为其他格式。下载过程中允许用户选择保存位置，不改变其操作名称。

复制和查看不会改变内容身份。用户下载内嵌结果时，系统根据内容类型生成对应文件并保存至用户选择的位置，但该文件不自动登记为本轮 Agent 的独立产物，也不自动加入置顶摘要的“输出内容”。

产物类型、展示与打开规则

同一产物按照主要内容类型归类。文件格式用于确定图标、预览容器和可用操作，不单独决定产物类型。

[table]

置顶摘要只保存产物索引，不重复保存或直接展示产物内容。点击索引后打开同一产物资源；文件默认在产品内预览，“使用默认应用打开”属于二级操作。

图像、图表与图示在不同入口采用不同的默认打开方式：从最终答复点击时直接进入整屏预览；从置顶摘要点击时先在右侧辅助工作区中打开预览，用户可再通过整屏按钮放大查看。

图表与图示按内容类型归类，但其下载、另存为和源码查看等操作由实际载体决定。例如，以 PNG 或 SVG 交付的图表按图像文件预览，以 HTML 交付的交互图表按网页方式打开。

具体文件格式在文件视图中的预览形态、优先级、实现难度和可用操作，统一纳入 F074 的文件类型能力说明。

产物记录

Agent 或产物工具生成独立产物时，应写入产物记录，至少包含：产物 ID、任务 ID、产物类型、名称、本地路径、网页地址或资源标识、创建或最后更新时间、是否可打开，以及是否已作为任务交付物输出。只有被标记为“已作为任务交付物输出”的对象，才进入最终答复和置顶摘要。

产物被删除、移动、失去访问权限或无法加载时，保留原条目并显示“暂不可打开”，点击后提示资源不可用，不自动删除历史记录。

3.9 F063 反馈最终答复

负向反馈采用结构化标签 + 补充说明的方式收集。反馈标签优先覆盖两类问题：

高频问题：用户较常遇到、可用于持续判断产品与模型体验的问题；


高风险问题：即使反馈量较少，一旦出现也需要重点关注的问题，如执行了不该执行的操作、安全或隐私问题。


标签应尽量描述可定位的具体问题，避免使用“没有帮助”“不满意”等无法判断原因的宽泛表述。具体标签内容及弹窗视觉样式以原型为准。

反馈交互规则如下：

点赞与点踩互斥，同一条最终答复仅保留一种反馈状态；用户切换反馈时，以最后一次提交结果为准。


点击点赞后直接记录正向反馈，并通过顶部气泡告知提交成功。


点击点踩后打开负向反馈弹窗，反馈标签支持多选。


未选择任何标签时不可提交。


默认不展示补充输入框；选择“其他”后展开输入框。


仅选择“其他”时必须填写具体问题，内容为空不可提交；未选择“其他”可直接提交；多选标签包括“其他”时无需填写补充说明也可提交。


负向反馈提交成功后关闭弹窗，并通过顶部气泡告知提交成功。

3.10 F069 展示置顶摘要容器

置顶摘要是当前任务的成果与来源查看入口，不承担创建、上传、编辑或执行任务的职责。

置顶摘要包含两个分区：

输出内容： 当前任务明确交付了哪些可继续使用的独立产物；

来源： 当前任务附加、检索或获取了哪些可追溯的信息资料。

置顶摘要不展示普通聊天消息、完整工具调用流水、终端日志、项目目录全量文件或无项目任务工作目录全量文件。某一类对象不存在时，不展示对应分区，也不展示空状态或创建入口。

3.11 F070 展示输出内容

输出内容只收录符合 F061 定义，并被明确作为任务成果交付的独立产物。产物由明确的产物记录生成，不根据工作目录中存在的文件或普通文件变更自动推断。

以下对象不进入输出内容：

普通最终答复文本、结论和代码块；

仅在最终答复中渲染、没有独立资源记录的表格、结构化数据、图表和图示；用户下载内嵌结果后生成的文件也不自动收录；

临时脚本、缓存、草稿、中间数据、终端输出、构建日志、测试日志和错误信息；

未被明确交付的普通代码修改或文件修改；

搜索结果、网页资料、用户附件和“我的资料库”资料；

仅因存在于工作目录或被编辑过而产生的文件。

同一产物在置顶摘要中的类型、名称和打开方式与 F061 保持一致。产物不可访问时，保留条目并显示“暂不可打开”。

3.12 F071 展示来源概览

来源用于记录任务获得过哪些可追溯的信息资料，不等同于最终答复的参考文献列表，也不表示每项来源都被最终结论采用。最终答复中的来源角标用于说明某一具体结论引用了哪项来源。

系统不得根据工具名称、文件扩展名或自然语言猜测来源。每类事件和工具能力应预先配置是否产生来源记录。

用户附加资料

用户从本地附加的图片、文件、文件夹或文本资料进入来源；

本地附件可在文件视图中打开，实际预览能力由文件格式决定；不支持预览时显示对应不可预览状态，并保留使用系统应用打开或其他适用操作；

用户从“数据资产 > 我的资料库”选择并附加的资料，在来源中标记渠道为“我的资料库”；第一版仅展示名称、在“我的资料库”中的路径和“已附加到对话”状态，不支持预览、打开或定位。

我的资料库检索

Agent 检索“我的资料库”并实际获得某个文件的文本片段时，按原始文件生成来源记录；

同一文件多次命中只展示一条，记录命中片段数量及是否被最终答复引用；

检索未命中时不生成来源记录。

网页搜索

网页搜索和通过搜索结果打开网页统一归入“网页搜索”；非搜索进入的网页作为“直接打开网页”归入同一分组；

同一 URL 多次打开只保留一条网页记录，并累计打开次数；

置顶摘要不展示来源总数，只提供“查看全部”入口；进入来源详情页后，“网页搜索”分组展示搜索次数、搜索词列表、打开的网页数量及链接。

只读工具结果

只有被产品配置为“来源结果”的只读工具调用才产生来源记录，例如读取项目或文档内容、查询数据库记录，以及从连接器或外部应用获取可引用对象。来源详情页按工具提供方分组，展示工具名称、调用次数和返回结果。

创建、编辑、保存、移动或删除文件，创建正式产物，发布、部署、发送消息、创建外部记录，构建、测试、运行命令，以及改变任务、界面或步骤状态，均不产生来源记录。

3.13 F072 打开关键对象

从置顶摘要打开文档、表格、数据、演示文稿、代码、配置或本地图像时，进入右侧文件视图；

从置顶摘要打开网页与交互应用时，进入右侧浏览器视图；

从置顶摘要打开图像、图表与图示时，先进入右侧预览，用户可通过整屏按钮放大；

点击“查看全部”进入来源详情页，再按来源对象类型执行对应的打开规则；



关闭文件预览、浏览器标签页、整屏预览或来源详情页后，返回原任务对话并保留原滚动位置；

对象被删除、移动、失去权限或无法加载时，保留历史条目并提示当前不可用。

3.14 F073 打开右侧辅助工作区

右侧辅助工作区只提供“文件”和“浏览器”两类工作视图。

用户主动打开辅助工作区且当前没有活动内容时，展示启动页，并提供“文件”和“浏览器”两个入口；

两个入口用于选择要创建的工作视图，不作为已打开内容的标签页；

点击“文件”后，创建文件标签页，并在整个右侧区域展示当前任务工作区的文件树；

点击“浏览器”后，创建浏览器标签页；

从最终答复或置顶摘要打开具体对象时，跳过启动页，直接创建或聚焦对应标签页；

文件标签和浏览器标签可以同时存在，统一排列在辅助工作区顶部，交互方式参照浏览器标签；

点击标签切换当前内容；鼠标悬停标签时显示关闭按钮，点击关闭按钮关闭该标签；

再次打开同一个文件、网页或其他对象时，聚焦已经打开的原标签，不重复创建；

打开不同对象时创建新标签；从文件树选择文件时，在当前文件标签中打开；

关闭当前标签后，自动切换到最近使用的其他标签；关闭最后一个标签后，返回“文件／浏览器”启动页。

3.15 F074 浏览、预览与操作任务文件

工作区范围

文件视图以当前任务的工作区为范围：项目任务展示项目关联的本地目录；无项目任务展示该任务的专属工作目录。

文件树与文件预览

文件树和文件预览在同一个文件标签页内切换，不采用左右分栏：

用户从启动页点击“文件”后，整个右侧区域首先展示文件树；

用户在文件树中选择文件后，当前标签页切换为文件预览；

文件预览顶部的文件树按钮用于返回文件树；

在文件树与文件预览之间切换时，保留目录展开状态、滚动位置和筛选条件。

文件树支持：

展开和收起目录；

按文件名筛选；

选择文件；

高亮当前预览文件。

文件预览顶部栏

文件预览顶部栏左侧展示当前文件在工作区中的相对路径面包屑，右侧固定展示文件树切换按钮和“打开”分裂式按钮。

路径过长时折叠中间层级，右侧操作区保持完整；

点击面包屑中的文件夹层级后，通过浮层展示该目录直属的子目录和文件；

在浮层中选择文件后，继续在当前标签页中预览。

“打开”主按钮使用系统默认应用打开当前文件，下拉菜单包括：

使用默认应用打开；

打开所在文件夹；

另存为。

文件预览边界

不同文件类型的预览形态、展示规则和可用操作由文件类型能力矩阵定义；

文件预览仅用于查看，不支持在产品内编辑和保存原文件；

HTML 在文件视图中查看源码，在浏览器视图中查看渲染后的页面。

代码查看器属于文件预览的一种只读预览形态，仅用于查看、查找和复制代码，不提供编辑、运行或调试能力；产品不提供用户可直接操作的终端入口，需要执行代码时由 Agent 在任务过程中调用对应工具，并遵循任务权限与过程记录规则。

3.16 F075 浏览网页与 HTML 内容

支持范围

浏览器视图用于打开：

公共网页；

任务生成的本地 HTML；

本地服务地址；

最终答复或来源中的网页链接。

本地 HTML 在浏览器视图中查看渲染效果，在文件视图中查看源码。

本地 HTML 可以加载当前工作区内通过相对路径引用的样式、脚本、图片和其他静态资源。资源不存在或无法加载时，在页面中保留对应异常状态，不导致整个网页预览退出。

本地 HTML 和外部网页均在隔离的浏览器环境中运行，不直接获得桌面应用能力、任务工作区写入权限或其他本地文件访问权限。页面需要访问外部网络时，遵循产品统一的网络与权限规则。

浏览器顶部栏

浏览器标签页提供：

输入和编辑 URL；

前进；

后退；

刷新；

使用系统默认浏览器打开当前页面；

关闭当前标签。

导航按钮在当前操作不可用时置灰。页面跳转后，地址栏和标签名称随当前页面更新。

标签创建与复用

用户从启动页点击“浏览器”时，创建一个空白浏览器标签；

从最终答复、置顶摘要或来源详情打开网页时，直接创建或聚焦对应浏览器标签；

同一网页地址或同一网页产物已经打开时，复用原标签并切换到该标签，不重复创建；

不同网页在不同标签中打开；浏览器标签与文件标签共用辅助工作区顶部的标签栏。

页面状态与异常

首版统一覆盖：

正在加载；

地址无效；

网络连接异常；

页面无法访问或加载失败；

外部网页拒绝内嵌或需要特殊登录环境；

本地 HTML 文件不存在或无法访问；

本地服务未启动或已经停止。

页面加载失败时保留当前地址和标签，展示失败原因，并允许用户刷新、修改地址或使用系统默认浏览器打开。外部网页拒绝内嵌或需要特殊登录环境时，优先引导用户使用系统默认浏览器打开；本地服务不可访问时，明确提示“服务未运行或已停止”。

页内查找、页面缩放、截图等效率功能不纳入当前统一规则，后续根据优先级另行确认。
