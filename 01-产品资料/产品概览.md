# TPT Work 产品概览

这是一份基于已有资料的阅读入口，描述历史被测产品；整理日期为 2026-10-05，没有运行产品或产生新的测试结论。资料覆盖的主体是 2026-09-29 至 09-30 的 Windows Electron 应用。

## 先理解三个关系

用户在项目或临时任务中发起会话，Agent 在该会话的工作目录里执行工具调用；场景预设影响它如何工作，权限档位影响它可以写到哪里。预设、权限、模型是不同维度，不能用“某预设成功”代替权限验证。

| 对象 | 资料中可确认的含义 | 阅读边界 |
|---|---|---|
| 项目 / 工作区 | 项目绑定目录，会话执行关联 cwd | 未绑定任务也有临时任务目录；历史路径不是当前配置 |
| 会话 / 任务 | 对话、执行过程与工具结果的载体 | 侧栏项目会话与最近/置顶项目的 UI 实现不同 |
| 场景预设 | standard、ptc、minimal、cordis，以及当时自定义 factory | factory 不应列成所有安装的内置预设 |
| 权限档位 | 仅可查看、工作区内修改、完全权限、Auto review | 和底层 acl/elevated 实现档位不是同一组设置 |
| 记忆 | 设计中的人格、用户长期记忆、工作日志与反思 | 设计流程不等于已经实现或全部验证 |

## 产品入口与功能区域

历史主页包含新任务、自动化、更多、项目、最近和置顶；任务页可查看对话和执行轨迹，输入区选择项目、预设、权限与模型/推理配置。更多区域涉及技能、插件、连接器、数据资产与专家等模块；换包后记录比早期多出连接器入口。

这些入口的存在不等于端到端业务能力已通过：IM 通道在插件描述中出现，但不能据此宣布消息发送、接收和回执已验证。自动化、轨迹等仍应按原记录区分观察和待测。

来源：[早期产品观察](../03-%E6%B5%8B%E8%AF%95%E6%89%B9%E6%AC%A1/%E6%97%A9%E6%9C%9F%E6%8E%A2%E7%B4%A2_%E5%8E%9F%E6%A0%B9%E7%9B%AE%E5%BD%95/01-product-info.md)；[换包后产品观察](../03-%E6%B5%8B%E8%AF%95%E6%89%B9%E6%AC%A1/20260929_2153/01-%E4%BA%A7%E5%93%81%E4%BF%A1%E6%81%AF.md)（主页、侧栏功能、设置模块章节）。

## 已有验证集中在哪里

| 主题 | 已有内容 | 主要限制 |
|---|---|---|
| 记忆与进化 | 设计对照、注入、召回、落盘、面板、换包回归 | 自动沉淀/反思链路存在原报告问题；不能把工具写入当成自动流程完成 |
| 场景预设 | 同题五模式比较、factory/standard 与 PTC/standard 定向比较 | 模型、题目与设置限定；cordis 插件创建等未验证 |
| 项目与任务 | 置顶、重命名、归档、未读、分享、排序等 | 部分早期疑点后来修正；拖拽与原生选择器覆盖有限 |
| 沙箱与权限 | 四权限档、磁盘/ACL、越界、诊断与设置入口 | 历史特定包和 Windows 环境；底层隔离不构成全面安全保证 |

## 版本身份与未明确的信息

早期资料分别记录 exe 文件版本 0.1.3.0 和设置页版本 0.2.0-rc.1，这是两个观测字段。后续批次记录 app.asar 为 253,660,790 字节、修改时间 2026-09-29 21:50:02；相同 exe 版本号不足以识别换包。这里没有补造包哈希或将目录日期当作发行版本。

资料中的模型选择、模块数量与用户目录都是当时快照；不能据此确定当前默认值。设置文档存在“9 项”标题而实际列出 8 项的不一致，保留为资料问题，没有补造第九项。
