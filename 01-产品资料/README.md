# 产品资料

先了解对象，再按当前功能查设计和来源，不要求通读所有原文。

## 1. 建立产品认识

读 [产品概览](产品概览.md)：了解项目、会话、场景、权限和记忆等对象。概览基于历史资料，不保证当前版本状态。

## 2. 查当前功能的依据

| 想了解什么 | 按需入口 |
|---|---|
| 需求与期望行为 | [原设计文档](原设计文档/README.md)，按功能分组 |
| 记忆设计 | [已有记忆设计文档](tpt-memory%20产品设计文档.md)，作者与来源待确认 |
| 历史实际行为 | [历史实测专题](../03-测试批次/专题整理/README.md)，再核对原报告 |
| 安装包组件与实现说明 | [安装包技术资料](安装包技术资料/README.md)，先读检查结论，再查具体文件 |

## 3. 判断适用性

设计、安装包说明、历史实测属于不同来源；开发中的部分需求尚未实现。与用例不符先标记差异，不自动认定缺陷或需求变更。

新观察与候选问题先放 [探索性测试待审核区](../探索性测试/README.md)，审核后再并入本目录。原文和来源清单保留，不把候选结论写成已确认事实。
