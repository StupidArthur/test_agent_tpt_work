## 命令行逐层发现

```powershell
node 04-测试工具/ui-operations/call.mjs --browse
node 04-测试工具/ui-operations/call.mjs --browse skills
node 04-测试工具/ui-operations/call.mjs --browse skills.use
node 04-测试工具/ui-operations/call.mjs --describe skills.useSkillDirect
```

明确关键词可直接 `--find "技能 快捷使用" --module skills --limit 3`；候选含义不清时回到场景比较用途。任务新增函数使用 `--find "关键词" --task <任务目录>`，不要求先加入共享分类。

拿到正确函数、参数来源、实际断言取值与恢复方法即可开始；仅异常或开发需要继续读深层资料。

本页与场景页由 catalog.json 和 discovery.json 生成。登记数量不等于实机验证数量。
