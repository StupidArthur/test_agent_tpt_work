# 按功能找工具

没有 case 编号时，从本页选一个功能模块。只读需要的模块，再对候选函数执行 `--describe`；不需要读全库源码。

本页由 business/catalog.json 生成，当前 180 个函数。登记数量不是实机验证数量。

| 功能 | 函数数 | 阅读入口 |
|---|---:|---|
| 接入与环境 | 2 | [application](modules/application.md) |
| 对话、任务、会话与权限 | 35 | [conversation](modules/conversation.md) |
| 附件 | 14 | [attachments](modules/attachments.md) |
| 技能 | 35 | [skills](modules/skills.md) |
| 专家 | 24 | [experts](modules/experts.md) |
| 设置与插件 | 27 | [settings](modules/settings.md) |
| 记忆与进化 | 6 | [memory](modules/memory.md) |
| 夹具、备份、文件与服务 | 11 | [fixtures](modules/fixtures.md) |
| 冒烟辅助 | 26 | [smoke](modules/smoke.md) |

## 有 case 编号时

优先 `node 04-测试工具/ui-operations/call.mjs --plan G10-07`，它返回该 case 的操作与取值候选。映射是选用提示，最终判据仍由本轮 case 决定；历史路径、session、call/event 不能直接复用。

## 阅读到哪里就可以开始

拿到正确函数、明确参数来源、知道读取哪些实际值和如何恢复，就可以调用。出现异常再读 [补测规则](../../../03-测试技能/exploratory-testing/references/retest.md)。
