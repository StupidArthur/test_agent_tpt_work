# 进入新建技能模式

[返回技能](../modules/skills.md)

只验证创建入口与模式，不代表技能已经创建。

| 候选函数 | 用途 |
|---|---|
| `skills.startCreate` | 点击新建技能并读取创建技能模式标识与面板可见 |

只对选中函数执行 `--describe <函数名>`；核对对象、参数来源、准备/恢复动作及实际取值后，按 [调用与记录](../调用与记录.md) 调用。候选不是业务通过判据。

命令行同一路径：`--browse skills.create`；场景内检索：`--find "关键词" --route skills.create --limit 3`。
