# 进入创建或对话编辑并发送

[返回专家](../modules/experts.md)

创建入口、编辑会话与实际写入分别判定；不得用助手回答代替文件落盘证据。

| 候选函数 | 用途 |
|---|---|
| `experts.startCreate` | 点击创建专家并读取创建专家模式标识 |
| `experts.startEdit` | 从专家详情进入对话编辑会话，读取引用/编辑模式/左侧导航 |
| `experts.editSend` | 在编辑会话发送消息并等待终态，返回助手正文 |

只对选中函数执行 `--describe <函数名>`；核对对象、参数来源、准备/恢复动作及实际取值后，按 [调用与记录](../调用与记录.md) 调用。候选不是业务通过判据。

命令行同一路径：`--browse experts.edit`；场景内检索：`--find "关键词" --route experts.edit --limit 3`。
