# 面板探查、概览与文件取证

[返回记忆与进化](../modules/memory.md)

结构探针用于定位，概览和文件用于实际取值；不代表沉淀、反思或晋升行为已验证。

| 候选函数 | 用途 |
|---|---|
| `memory.inspectSurfaces` | 枚举记忆与进化面板与设置记忆分区的文本与控件（本轮定位用） |
| `memory.probePanel` | 切记忆面板 tab / 打开编辑弹窗 / 高级设置并读取结构 |
| `memory.readOverview` | 读取概览计数/开关与高级设置实际参数值 |
| `memory.readFiles` | 枚举记忆目录并读取各文件内容与哈希 |

只对选中函数执行 `--describe <函数名>`；核对对象、参数来源、准备/恢复动作及实际取值后，按 [调用与记录](../调用与记录.md) 调用。候选不是业务通过判据。

命令行同一路径：`--browse memory.observe`；场景内检索：`--find "关键词" --route memory.observe --limit 3`。

涉及本机记忆文件或写入时再读 [记忆与进化](../记忆与进化.md)。
