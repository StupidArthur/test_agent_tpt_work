# 首次使用：完成一次真实读取

[返回工具入口](../README.md)

## 1. 先确定任务和操作通道

先读本轮任务 README、根 AGENTS 和 [探索性测试技能](../../../03-测试技能/exploratory-testing/SKILL.md)。本库通过 Electron 的 CDP 使用 Playwright；安装、启动、登录按 [TPT Work 接入技能](../../../03-测试技能/tpt-work-access/SKILL.md) 完成。已知准确exe、窗口标题和实际CDP端口时，可从 [复用或授权启动](scenarios/application.startup.md) 查组合工具，核对进程/端口、显示状态与实际页面；登录仍按接入技能和本轮授权执行。

新环境先按 [环境检测工具集](../../environment-check/README.md) 一次检测必需工具并读取使用指南；已有同环境、同项目的有效结果直接复用，不再手查版本或依赖目录。

**Playwright 依赖判定**：本库连接已有 Electron/CDP，`playwright-core` 或 `playwright` 任一能从本项目解析、导入且提供 `chromium.connectOverCDP` 就满足依赖要求。环境报告中 `nodejs-playwright.status=ok` 时直接使用返回的 `selected_package`，不再安装；只查 `node_modules/playwright` 不存在不能判缺依赖。只有报告为 `missing` 且有准备依赖的授权时，才按本项目 `package.json` 安装。`execution_error`、`timeout` 或 `dependency_unavailable` 先定位对应原因，不用安装代替诊断。CDP接入不需要下载Chromium；夹具生成需要Python。

## 2. 建立本轮环境文件

在本轮任务目录建立 UTF-8 `环境记录.json`。下面端口只作示例，必须核验本机实例：

```json
{
  "environment_id": "本机-本轮唯一编号",
  "cdp_endpoint": "http://127.0.0.1:9234",
  "account_name": "本机当前账号",
  "ui_timeout_ms": 5000
}
```

涉及技能、专家、项目或 Python 时，再按本机实际位置补 `skills_registry`、`skills_root`、`agents_root`、`project_path`、`python`。设置初值、对象身份和共享样本放本轮 `运行上下文.json`，按任务约定填写；不要复制历史运行上下文当成本轮状态。

## 3. 查契约，再调用

下面示例适用于首次试用连接读取、或目标只核对已有CDP连接。已有明确业务/窗口/真实实例目标时，直接选相应场景与函数，不先执行本示例；打开/复用应用按 [复用或启动](scenarios/application.startup.md) 的条件指导补字段并调用。

只核对连接时查：

```powershell
node 04-测试工具/ui-driver/call.mjs --describe application.inspectConnection
```

在本轮任务目录建立 UTF-8 `参数.json`，内容为 `{}`，再调用。将示例任务路径换成本轮真实路径，命令在仓库根执行：

```powershell
node 04-测试工具/ui-driver/call.mjs application.inspectConnection --task "05-探索性测试/本轮任务" --args-base task --args-file "参数.json"
```

核对返回中的 Electron target 与当前应用，不能连接到普通浏览器页面就继续。

`--task` 相对调用cwd解析。`--args-base task` 明确把相对参数文件以该任务目录为基准；默认或显式 `--args-base cwd` 保持旧行为，以调用cwd为基准。绝对参数路径不变，单次和 `--batch` 同规则。选定位置缺文件时直接失败并报告解析路径，不尝试另一位置；cwd/task同名文件不会静默混用。参数JSON支持UTF-8 BOM；本轮环境记录仍按既有UTF-8无BOM契约准备。

Windows的 `C:参数.json` 或 `\参数.json` 带根信息但仍依赖当前驱动器/目录，task模式拒绝这类模糊输入。使用 `C:\完整目录\参数.json`、完整UNC路径，或不带驱动器/根前缀的任务相对路径。默认cwd行为保持兼容。

## 4. 开始当前 case

有 case 编号：

```powershell
node 04-测试工具/ui-driver/call.mjs --plan G10-07
node 04-测试工具/ui-driver/call.mjs --describe skills.useSkillRequest
```

没有 case 编号：先执行 `--find "技能 快捷使用" --limit 3` 找少量候选；不确定模块时用 `--modules` 或读 [功能索引](功能索引.md)。`--find` 忽略大小写，按空格分词，不是语义搜索；搜不到时换词或缩短查询。需要查看一个模块全部工具时再用 `--list skills`。

拿到函数后，继续 [调用与记录](调用与记录.md)。不要先通读整个 catalog 或历史测试日志。
