# 个人主页身份只读性

[返回设置与插件](../modules/settings.md)

仅验证实际身份字段是否只读。

| 候选函数 | 用途 |
|---|---|
| `settings.readProfileIdentity` | 读取个人主页身份字段是否均只读 |

只对选中函数执行 `--describe <函数名>`；核对对象、参数来源、准备/恢复动作及实际取值后，按 [调用与记录](../调用与记录.md) 调用。候选不是业务通过判据。

命令行同一路径：`--browse settings.profile`；场景内检索：`--find "关键词" --route settings.profile --limit 3`。
