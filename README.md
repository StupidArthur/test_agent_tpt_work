# TPT Work 产品与测试资料

这套资料用于理解产品、复用测试方法、解释历史质量证据。2026-10-05 完成目录归类与正文整合；整理时未运行产品或产生新的质量结论。原始记录、证据和交付副本完整保留。后续 CDP 接入验证另记在测试方法文档中。

## 三层阅读

1. **先建立整体认识：** [产品概览](01-%E4%BA%A7%E5%93%81%E8%B5%84%E6%96%99/%E4%BA%A7%E5%93%81%E6%A6%82%E8%A7%88.md) → [历史测试总览](03-%E6%B5%8B%E8%AF%95%E6%89%B9%E6%AC%A1/%E5%8E%86%E5%8F%B2%E6%B5%8B%E8%AF%95%E6%80%BB%E8%A7%88.md)。先看对象、验证范围和未知项。
2. **按问题深入：** [测试接入与执行指南](02-%E6%B5%8B%E8%AF%95%E6%96%B9%E6%B3%95%E4%B8%8E%E6%8A%80%E6%9C%AF%E5%8F%82%E8%80%83/%E6%B5%8B%E8%AF%95%E6%8E%A5%E5%85%A5%E4%B8%8E%E6%89%A7%E8%A1%8C%E6%8C%87%E5%8D%97.md)；[四个测试专题](03-%E6%B5%8B%E8%AF%95%E6%89%B9%E6%AC%A1/%E4%B8%93%E9%A2%98%E6%95%B4%E7%90%86/README.md)；各批次摘要。整合结论均链接原来源。
3. **核对原始材料：** 原报告 → evidence / refs / 交付包；旧路径通过 [资料地图](00-%E5%AF%BC%E8%88%AA%E4%B8%8E%E6%95%B4%E7%90%86%E8%AE%B0%E5%BD%95/%E8%B5%84%E6%96%99%E5%9C%B0%E5%9B%BE.md) 找到。

Agent 要操作或测试本机 TPT Work 时，直接从[CDP + Playwright 默认执行路线](02-%E6%B5%8B%E8%AF%95%E6%96%B9%E6%B3%95%E4%B8%8E%E6%8A%80%E6%9C%AF%E5%8F%82%E8%80%83/portable-agent-exe-ui-api-guide.md#agent-默认执行路线先读)开始；API / wire 测试使用同一指南中的独立测试网关入口。

探索性测试产出统一先进入[探索性测试待审核区](探索性测试/README.md)，经用户或指定审核者审核通过后，再并入正式产品资料与测试方法。

## 读结论前的边界

历史批次不等于当前版本；目录日期不等于发行版本。人工夹具、产品产物、模型复述和推断不是同类证据。后续修正与早期报告一起读：空索引不证明召回失败，归档提示已在后续验证，目录权限问题不能归因于盘符。历史 RULES 仅保留其范围。
