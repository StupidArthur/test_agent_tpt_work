# 测试项

按要评估的能力组织测试范围、方法、检查清单与历史依据。实际执行另建探索性测试任务；本目录不代表已有当前版本的通过结论。

| 测试项 | 范围 | 入口 |
|---|---|---|
| LLM 网关服务评估 | 通用 API、供 TPT Work 使用的协议、性能和用户并发；不含软件操作 | [saas-llm-test](saas-llm-test/README.md) |
| 沙箱与提权沙箱测试 | 权限、受限执行、审批、ACL 边界、诊断和 elevated 实现 | [测试项入口](沙箱与提权沙箱测试/README.md) |
| 记忆与进化功能测试 | 写入、注入、召回、自动沉淀、反思晋升、管理与恢复 | [测试项入口](记忆与进化功能测试/README.md) |

渐进阅读：测试项 README → 当前功能的测试设计 → 对应历史记录 → 必要时查原始证据。历史批次保留在 `03-测试批次`，本目录按主题整合，不复制统计为新的测试轮次。

分派与产出遵循 [执行任务约定](执行任务约定.md)：历史删减需用户确认，强制工具调用与任务函数留存，各 PC 独立记录，结果统一进探索性测试任务。
