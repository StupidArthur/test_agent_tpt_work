本目录定义测什么、为什么测、如何判断和如何报告，只评估网关供 TPT Work 使用的 API 服务，不操作软件 UI。执行过程与原始证据留在探索任务；审核后的正式现状和报告落在 `05-测试结果/`。

|核心测什么、默认流程|[测试方案](docs/01-需求与范围.md)|

五分钟阅读：先看方案，再看指标与容量，最后按任务选 case。无需先读全部历史编号、todo 或证据。

三层：**A 用户体验 → B 通用性能解释 → C 兼容性/诊断支撑**。核心测试回答用户问题，诊断测试解释问题。生产实际模型、reasoning 和协议优先；能力强不代表每轮全测。
