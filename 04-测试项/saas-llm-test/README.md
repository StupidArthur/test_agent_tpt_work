# LLM 网关服务评估

评估网关提供的 LLM API 是否满足 TPT Work 的调用契约，以及它在明确负载下的延迟、吞吐、稳定性和用户并发承载能力。

**不测试 TPT Work 软件操作、UI、登录、设置或产品功能。本目录交付测试设计；新版测试代码和实际执行由后续 Agent 完成。当前没有新的网关实测结论。**

## 测试分层

1. **通用 API：12 个测试项**。发现、文本、流式、上下文、工具调用、鉴权、错误、计量和输出约束。
2. **TPT Work 网关契约：10 个测试项**。直接向网关发送宿主所需的 Responses 请求，检查返回是否能被适配器消费。
3. **性能：8 个测试项**。短请求、首个有效内容、长输出、上下文、思考档、网络和持续稳定性。
4. **容量：6 个测试项**。请求并发、用户会话负载、工具工作流、边界复核、开放到达和恢复。

共 **36 个测试项**。模型、思考档、样本和负载档位会展开成多个执行实例，36 不是 HTTP 请求数量。条件项缺条件时登记“未验证”；不凑通过率。
