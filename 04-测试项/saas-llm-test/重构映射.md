# LLM 网关测试体系重构映射

性质：长期设计与资料治理，不执行网关请求。先完成本映射，再修改正式文档。依据用户本次任务，调整默认执行范围；不删除原断言、原编号和历史结果。

## 三层定位

- A 用户体验：普通交互、标准 Agent、上下文增长后的等待、3/5/10 秒活跃用户容量。
- B 通用性能：Success Rate、TTFT、E2E、Output tokens/s、Requests/s、Agent turns/s、Error Rate / 分布。
- C 兼容性/诊断/条件：最小 Gateway Compatibility Smoke 为可信前置；详细协议与故障矩阵按依赖、声明或问题触发，主报告只给能力小表。
