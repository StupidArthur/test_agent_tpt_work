# 账号与应用

[返回功能导航](README.md)

| 已有功能与实际行为 | 如何操作 | 回读重点与来源 |
|---|---|---|
| 账号密码登录，成功后进入新建任务首页 | 登录页选账号密码页签，填写凭据、记住密码与协议后提交；[登录工具](../04-测试工具/ui-driver/docs/scenarios/application.login.md)：readLoginPage → loginWithPassword | 登录页消失、首页可见、左下角账号匹配；用 application.readHomeAccount。SMK-01 并非全新安装样本，不能据此证明首次安装全部行为 |
| 账号菜单退出登录，有二次确认 | 左下角头像 → 退出登录 → 确认；[账号工具](../04-测试工具/ui-driver/docs/scenarios/application.account.md)：readAccountMenu / logout | 登录页出现；主页面可能仍存在，不能以它未销毁判退出失败。SMK-02；原轮重新登录后用户名预填 |
| 打开或绑定本机应用实例 | [接入技能](../03-测试技能/tpt-work-access/SKILL.md) → application.open | 工具支持核验进程、窗口和页面身份；这些是接入能力，不是登录成功判据 |
| 完全结束应用进程 | [退出工具](../04-测试工具/ui-driver/docs/scenarios/application.quit.md)：application.quit，先查契约取得准确实例身份 | 这是终止绑定进程树的工具操作，不是产品菜单退出；回读 exited 和残留进程，不把窗口隐藏或 CDP 断开当成退出 |

登录账号使用本轮指定凭据文件，传 credentialsPath；不在导航中抄录密码。退出登录可能中断执行中的任务，须符合本轮测试范围。

## 来源与使用

[smoketest 用户确认结果](../02-测试项/TPT Work冒烟测试/smoketest-1012-用户确认结果.md)保留 SMK 编号、实际值与 call_id；主样本为 0.1.3-nightly.202610111943，后附 0.1.4 名称对照。当前参数以工具契约为准，历史通过不表示新版本通过。

已知函数用 `node 04-测试工具/ui-driver/call.mjs --describe <函数名>` 查参数，再按[调用与记录](../04-测试工具/ui-driver/docs/调用与记录.md)执行。本页只总结行为和操作路线。
