# 附件、技能、专家、设置与记忆

[返回功能导航](README.md)

本页来自 ui-driver 操作总结和[2026-10-07 回归验收](../05-探索性测试/2026-10-07-全面回归验收/验收报告.md)，不是 smoketest 的覆盖声明。验收接受部分原证据并做针对性补测，没有重新跑完所有用例；具体版本以原记录为准。

| 功能 | 如何操作及工具入口 | 已知操作边界 |
|---|---|---|
| 本地附件 | 输入区“添加本地文件” → 选文件 → 读草稿列表 → 需要时移除/清空 → 发送后检查附件气泡；[附件](../04-测试工具/ui-driver/docs/modules/attachments.md)，addLocalFiles / readDraftState / removeAttachment | 草稿卡存在不证明模型完成解析；预览和发送后气泡各有独立场景 |
| 技能导入、管理、预览 | 技能入口 → 导入 SKILL.md 或 ZIP → 查看反馈及准确卡片身份；再按需启停、打开详情与目录树；[技能](../04-测试工具/ui-driver/docs/modules/skills.md) | 验收观察 ZIP 候选列表、目录身份、坏包与垃圾文件处理差异，不能把任意 ZIP 导入视为已可靠支持 |
| 在对话中使用技能 | 快捷使用引入引用 → 发请求 → 读回复与技能轨迹；[技能使用](../04-测试工具/ui-driver/docs/scenarios/skills.use.md) quickUse / useSkillDirect / useSkillRequest / readTraceSkillContent | G3-03 实测快捷使用复用当前会话；useSkill 会主动新建，不能用它证明入口自行新建。模型读文件补偿不证明技能正常加载（G10-08） |
| 专家导入、详情与编辑 | 专家入口 → 导入并读目标卡片 → 详情读提示词，或进入对话编辑；[专家](../04-测试工具/ui-driver/docs/modules/experts.md) | 详情长文需实际滚动核验末尾；编辑的确认前后文件变化要独立验证（G11-04/10）；坏 metadata 反馈有历史差异 |
| 在对话中使用专家 | 引入专家 → 发请求 → 读正文与专家注入轨迹；[专家使用](../04-测试工具/ui-driver/docs/scenarios/experts.use.md) useExpert / useExpertRequest / readTraceExpertContent | 引用成功和规则生效分别判断；useExpert 自带新建会话准备 |
| 主题、语言、字号 | 设置 → 常规 → 保存初值 → 修改 → 检查实际显示 → 重开与恢复；[外观](../04-测试工具/ui-driver/docs/scenarios/settings.appearance.md) readGeneral / setTheme / setLanguage / setFontDelta | 选中值不代替颜色、导航语言、正文样式等实际效果 |
| 默认权限、插件、快捷键、个人主页 | 通过[设置分类](../04-测试工具/ui-driver/docs/modules/settings.md)选择具体场景，按目标行读取/修改并恢复 | 当前任务权限另见专题；记忆开关历史出现真实保存错误（G12-04/05），快捷键原生响应仍缺证据（G12-09） |
| 记忆面板、添加与分层编辑 | 账号菜单“记忆与进化” → 读面板或目标条目 → 备份 → 添加/编辑 → 回读文件 → 恢复；[记忆操作总结](../04-测试工具/ui-driver/docs/记忆与进化.md)，probePanel / readOverview / addEntry / editLayerFile / readFiles | 本机审核试用支持这些有限操作；自动沉淀、反思、晋升、分层注入不由面板或文件存在证明。高级参数显示不代表生效 |

每次只进入当前功能的场景，再对选中函数执行 --describe。工具未提供或历史仍待补证的行为，记录缺口；不从设计文档补写为“已经实现”。
