# 会话与产物

[返回功能导航](README.md)

| 已有功能 | 如何操作 | 实际结果与核验 |
|---|---|---|
| 新建空白任务 | 左上角“新建任务”；[基础会话工具](../04-测试工具/ui-driver/docs/scenarios/conversation.session.basic.md) conversation.newTaskOnly | 新 session 与输入框；SMK-03/04。只测新建时不提前发送请求 |
| 发送消息并生成回复和会话标题 | 输入框填消息、发送，等待新回合终态；[执行工具](../04-测试工具/ui-driver/docs/scenarios/conversation.execution.md) sendMessage / readTaskState；probeSidebar 读取标题 | SMK-03/04 发送与标题生成可观察，但严格回复内容出现差异。发送成功不能代表模型按要求回答 |
| 切换历史会话 | 读侧栏目标标题并切换；[基础会话工具](../04-测试工具/ui-driver/docs/scenarios/conversation.session.basic.md) probeSidebar / switchSessionByTitle | session 身份变化，正文对应目标会话；SMK-04/04R。使用本轮唯一标题，避免历史同名干扰 |
| 在项目中创建新会话 | 项目行的新会话入口；[项目会话工具](../04-测试工具/ui-driver/docs/scenarios/conversation.project.session.md) newSessionInProject | 项目归属、session、侧栏嵌套行；SMK-08 |
| 生成文件与侧栏预览 | 在已选项目会话发送生成请求 → 等待 → 找到真实文件链接 → 打开 → 读右栏；[预览工具](../04-测试工具/ui-driver/docs/scenarios/conversation.artifact.preview.md) readArtifactLinks / openArtifactLink / readSidePanel | SMK-09 观察 md/txt/html/docx 预览；docx 需等渲染结束。链接出现、文件落盘、内容正确和预览可见分别核验，不以助手自述代替文件证据 |

需要新建项目或绑定工作目录，转[项目与文件夹](项目与文件夹.md)；回复停在审批或问题卡时，转[权限与审批](权限与审批.md)，不要直接当作超时重发。

## 来源与使用

[smoketest 用户确认结果](../02-测试项/TPT Work冒烟测试/smoketest-1012-用户确认结果.md)保留 SMK 编号、实际值与 call_id；主样本为 0.1.3-nightly.202610111943，后附 0.1.4 名称对照。当前参数以工具契约为准，历史通过不表示新版本通过。

已知函数用 `node 04-测试工具/ui-driver/call.mjs --describe <函数名>` 查参数，再按[调用与记录](../04-测试工具/ui-driver/docs/调用与记录.md)执行。本页只总结行为和操作路线。
