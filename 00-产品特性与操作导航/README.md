| 功能目标 | 操作知识 |

## 知识依据

- 核心流程来自 [smoketest 用户确认结果](../02-测试项/TPT Work冒烟测试/smoketest-1012-用户确认结果.md)，操作函数对应[冒烟工具映射](../02-测试项/TPT Work冒烟测试/工具映射.json)。保留失败和模型输出差异，不把整条用例失败解释为所有步骤不可用。
- 扩展功能来自 ui-driver 的[回归验收](../05-探索性测试/2026-10-07-全面回归验收/验收报告.md)、[记忆操作总结](../04-测试工具/ui-driver/docs/记忆与进化.md)及场景契约。工具存在只表示有操作入口；专题页另列实测限制。
- 日期、版本和结论沿用来源；本轮整理没有重新操作产品。新版本不一致时记录新证据，再更新特性。设计文档只作对照，不用于认定功能已实现。

需要完整执行用例时进入[冒烟测试项](../02-测试项/TPT Work冒烟测试/README.md)；查更多操作进入[工具分类](../04-测试工具/ui-driver/docs/功能索引.md)。安装、派工和交付等工作入口见[根 README](../README.md)。
