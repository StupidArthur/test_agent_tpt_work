# 验收入口

1. [逐条验收.md](逐条验收.md)：140条用例逐条检查，明确原判定、证据边界和修正方法。
2. [实机复核补充.md](实机复核补充.md)：用户授权本机复测后，补入记忆/沉淀真实保存失败、快捷键正确入口与权限当前显示。汇总以该补充为准。
3. [逐条验收.json](逐条验收.json)：全部229项原断言、完整关联读取事件、源文件/行号/哈希，便于回溯。
4. [实机证据索引.json](实机证据索引.json)：补测证据的用例关联与SHA-256。

综合审核：75认可通过、9产品差异候选、48需补测或修正执行、5需修订用例判据、3原失败属于取值误判。产品差异尚待双方审核，未入库。原结果100通过/40失败保持不变。

执行 `node 审核/verify-audit.cjs` 可检查覆盖与原文件哈希；该命令只读历史执行文件，更新补测证据索引。下一轮已交接用例保持原版本，不在另一 Agent 执行期间修改判据。
