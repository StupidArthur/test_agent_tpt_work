## G12-04 / G12-05：实际保存失败

两个控件实际是 `.tpt-cfg-row` 内的 `input[type=checkbox]`，不是 `role=switch`。按“启用记忆”及“启用沉淀”的行标签分别定位。

| 项目 | 初值 | 点击后立即 | 1.5 秒后 | 重开 | 最终回读 |

| 启用记忆 | true | false | true | true | true |
| 启用沉淀 | true | false | true | true | true |

两次变化后均明确显示：`保存失败：Plugin entry "tpt-memory" has no volatile fields`。

**审核补充 AUD-LIVE-001：** 两条原执行的 null→false 不能证明产品失败；这次正确定位并实际点击，取得保存错误及回弹，支持“当前实例无法关闭记忆/沉淀”的产品差异候选。错误指向插件配置的 volatile 字段约定，但没有请求/后端栈证据，不能据此断言具体源码根因。建议检查这两个设置提交所调用的插件配置更新接口，核对 `tpt-memory` 字段注册与保存接口的约定，再重跑 true→false→重开→true 恢复。

证据：[完整单次复测](复测/memory-save-1791271539813.json)、[逐动作记录](复测/memory-actions.jsonl)、[控件身份](复测/memory-inputs-1791271386710.json)。哈希见 [实机证据索引.json](实机证据索引.json)。没有为文字可读的失败额外截图。
