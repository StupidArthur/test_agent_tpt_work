# 创建测试任务

选择一种模式，复制为 `05-探索性测试/<本轮任务>/README.md`，填好目标、范围、PC、通道、前置和恢复，再分派。

| 目的 | 模板 | 用例准备 |
|---|---|---|
| 按已定用例测试 | [常规测试](readme_for_test.md) | 分派前填好或引用既有用例 |
| 探索未知行为 | [探索发现](readme_for_discovery.md) | 可从空检查点开始，由 Agent 在范围内生成 |
| 核验指定问题 | [缺陷复测](readme_for_retest.md) | 明确原问题、证据和本轮复测步骤 |
| 同时评估用例质量 | [用例试运行](readme_for_case_trial.md) | 冻结待评估用例，修订建议另记 |

队列用 `测试用例.md` 或明确引用的现有文件，保持一个权威来源。产物按需生成；模板链接按任务位于探索目录下一层设计，改变层级时调整相对路径。
