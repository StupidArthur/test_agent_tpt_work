## 6.4 重启 SOP（✅ 2026-09-29 实践）

### 6.5.1 列表结构

侧栏为「三区 + 两 tab」结构：

| 区块 | 说明 | 落盘字段 |
| --- | --- | --- |
| **tab** | `任务` / `IM 频道` 两个页签 | `tab` |
| **置顶区** | 仅有被置顶会话时出现；**可折叠** | `expanded.pinned` / `pinned[]` |
| **项目区** | 工作区分组；**可折叠**；含 `新建项目` | `expanded.projects` / `panelProjects[]` |
| **最近区** | 未归属项目（未分组）的会话；**可折叠** | `expanded.recent` / `recentOrder[]` |

- 折叠阈值：**每组只显示 5 条**，其余折叠为 `展开其余 N 个会话`（点击展开）
- 空态：`暂无任务`（图标在上、文字在下，居中）
- 计数联动正确：置顶 1 条 → 最近区 `展开其余 13` → **12**；归档 1 条 → **11**（实测符合）

### 6.5.2 排序方式

| 项 | 说明 |
| --- | --- |
| `最近更新` | 按更新时间排序 |
| `手动排序` | 按用户拖拽顺序（**当前默认**，带 ✓） |

- 菜单结构：标题 `排序方式` + 上述两项（**无其它筛选项**）
- 选中态用 **svg 对勾**表达，**无 `aria-checked` / `aria-selected`**（自动化定位需靠 DOM 内 svg 判断）
