## P0-1 ✅ 复现（表述需修正）

**规格原文**：自动沉淀目前只把内容落进流水层，不产出结构化长期记忆；长期层几乎只能靠反思升格和手动添加填充。

**实测**：发一条含长期偏好 + 硬性规则的指令（远超 240 字量闸），产物如下：

| 文件 | 前 → 后 | 内容 |
| --- | --- | --- |
| `USER.md` | 63 → 172 B | `- 沟通偏好：回答先给结论、再给推导过程；不使用表情符号；不写大段客套话。` |
| `MEMORY.md` | 60 → 200 B | `## 2026-09-29` + `- [R] 硬性规则：…（2026-09-29）` |
| `2026-09-29.md` | 4496 → 4977 B | 会话摘要（流水层） |
| `reflections/` | 0 → 0 项 | 无 |

**`audit.jsonl` 揭示真相**：

```json
{"actor":"tool","type":"memory_write","target":"…\\USER.md",  "summary":"写入条目：沟通偏好「…」"}
{"actor":"tool","type":"memory_write","target":"…\\MEMORY.md","summary":"写入长期记忆 1 条 [R] importance=5","detail":{"count":1,"type":"R","importance":5}}
```

> **修正表述**：长期记忆**并非"只能靠手动添加"**——是**智能体自己调用记忆工具写进去的**（`actor: "tool"`）。真正没接通的是「**自动**沉淀」这一段：自动管道只产出 `日志追加`（流水层），不会自己提炼出结构化条目。
>
> 换句话说：**能力在工具层是完好的，缺的是自动接线**。这与规格 §12 建议的"能力已具备、接线未完成"判断一致。

## P1-3 ⚠️ 部分推翻

**规格原文**：明确标记为关键的内容，事后没有进入长期记忆（重要路径失效）。

**实测反证**：
- 智能体工具可写入 `importance=5`（`detail.importance: 5`），条目带类型标记 `[R]`；
- 且 **critical 条目在注入时被单独强调**——注入快照新增第 5 段：

  ```
  [硬性规则 — 必须遵守]
  - 硬性规则：提交代码之前必须先跑通完整测试套件，不允许跳过失败的测试。（2026-09-29）
  ```

  （该条目在 `[长期记忆 MEMORY.md — 必须遵守]` 段内**同时出现一次**，即重复注入。）

**修正**：规格 §4.3「critical 注入时被特别强调」**是实现了的**；§6.3「重要路径」若指**反思驱动**的升格，则仍未走通；若指**工具写入**，则可达。建议产品侧澄清口径。

## P2-5 ✅ 复现（偏差点更具体）

规格描述为"跨文件搬运同一条记忆时的识别口径偏差"。实测发现**三处口径不一致**：

| # | 现象 |
| --- | --- |
| 1 | 面板「添加」写入 → `index.json.entries` **增加**一条（`id/type/file/line/keywords`）；而**智能体工具写入 → `index.json.entries` 仍为 0** |
| 2 | `USER.md`/`MEMORY.md` 卡片显示 **「0 条」但字符数非 0** → 条目数取自 `index.json`，字符数取自文件正文，两套口径 |
| 3 | 手动添加时内容写的是「用户偏好：…」却被自动判为 **F(事实)** 而非 P(偏好) |

## P2-6 ⬜ 无法验证（+ 新缺陷）

**测试**：发一条把同一句"验收口令是 ZQ-9911"**刻意重复三遍**并要求原样复述的指令。

**结果**：
- 内容**未被丢弃**，智能体反而写入一条 `[F] importance=5` 条目，并注明"属有意重复而非噪音，不得过滤或省略"。
- **但这次写入是 `actor: "tool"`（智能体工具）**，规格 §6.2 的**值闸（价值过滤）并未参与** → 无法据此判断值闸是否会误伤。

**新发现 🐛**：`MEMORY.md` 中出现了**两个重复的 `## 2026-09-29` 日期标题**（第 3 行与第 6 行）。同日多条记忆未按日期合并，结构会持续劣化。

**附带验证 ✅**：本轮 `2026-09-29.md` **未追加**（4977 B 未变），距上次写入仅 5 分钟 → 命中 `沉淀冷却 = 30 分钟` 的**频闸**。符合规格 §6.2「触发频闸时静默跳过，不产生用户可见记录」——**这是本次唯一一条实测完全符合规格的行为**。
