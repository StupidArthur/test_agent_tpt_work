# 摸软件规则（Agent ↔ 操作者 约定）

> 版本：v1 · 2026-09-29
> 适用：本目录（`F:\electron-ui\tpt-work-notes\`）下所有探索、记录与产品信息入库
> 本文件是"玩法规则"的唯一出处，Agent 每轮探索前须先读它。

## 1. 角色分工

| 角色 | 职责 |
| --- | --- |
| **操作者（你）** | 带路、给方向、指定"看什么"，最后确认结论 |
| **Agent（我）** | **所有实际操作都由我来做**：点击、输入、切换、发送；每步自己截图取快照；自己记录；提交你确认后入库 |

- 操作者**尽量不手动操作**软件。
- **唯一例外**：CDP 碰不到的 **Windows 原生弹窗**（如"选择项目"的文件夹选择器、删除确认框）。这类由操作者代操作，Agent 必须记录"为什么由人来点"。

### 🛑 原生弹窗应急规则（2026-09-29 补充）

**原生模态框会阻塞渲染进程**：一旦弹出，CDP 的 `/json/*` 仍返回 200，但 `Runtime.evaluate` / `Input.*` / `Page.captureScreenshot` **全部挂起不返回**。

处置顺序：

1. **立即停手**，不要重试任何 CDP 命令（会一路超时）。
2. 用**系统级截屏**（`capture-window.ps1` / 整屏 `CopyFromScreen`）确认弹窗内容——这条通道不依赖 CDP。
3. 告知操作者，由人工关闭或确认。
4. 恢复后**先做只读复核**（`/json/version` + 一次 `shot`），确认没有误操作。
5. 在日志中标注该交互的定位方式与"需人工代操作"的原因。

> 已确认会触发原生弹窗的交互：记忆库「删除」的确认框。


## 2. 单步循环（核心规则）

**一次只做一个动作**，做完立刻：

1. **动作**：说清我点了什么 / 输入了什么（定位器或坐标）。
2. **快照**：自己截图 + 取结构化快照（文本 / `role` / `aria` 查询），两个证据都要。
3. **响应**：记录软件的**实际反应**（文字变化、弹窗、任务状态、用量/token、URL、控制台报错）。
4. **判定**：成功 / 异常 / 存疑。
5. **记录**：写入 `02-exploration-log.md`。

**禁止**：连续多步不留观察点；把一串操作塞进一次调用；用"我记得应该是…"代替实际快照。

## 3. 快照定义与命名

| 类型 | 手段 | 说明 |
| --- | --- | --- |
| 视觉快照 | `Page.captureScreenshot` → `.tpt-agent\<NN>-<语义>.png` | 首选 |
| 结构快照 | body `innerText` + 关键元素 `role/aria` 查询 | 与截图配对 |
| 兜底快照 | 无 CDP 的手动实例 → Win32 `PrintWindow`（`.tpt-agent\capture-window.ps1`） | **只读**，能看不能点 |

命名：`NN-<语义>.png`，`NN` 全局递增不重号；语义用小写英文/拼音，避免中文文件名。

## 4. 入库流程（三步）

```
草稿  →  向操作者复述确认  →  确认后写入产品信息
```

1. **草稿**：观察先落到 `02-exploration-log.md`（含动作、快照、响应、判定）。
2. **确认**：向操作者复述"我做了什么 + 软件怎么响应 + 我判定它是/不是什么"，**等你拍板**。
3. **入库**：你确认后，才写进 `01-product-info.md`，并标注 `✅ 已确认（操作者）`。
   未确认的只标 `🟡 待确认`，**不得**写成"产品特性"。

每条产品信息都要能指回证据（截图文件名 / DOM 查询 / 命令输出）。

## 5. 安全与边界（红线）

- 不擅自改配置、不擅自开关能力、不擅自删改文件；**只有你明确要求**才动。
- **高危能力**（"桌面操作""浏览器操作"）默认不开启；要点也必须先问。
- 只在被测软件范围内操作；**不动**其它进程 / 窗口 / 文件。
- 结束实例只结束**本轮自己启动且已核实命令行**的那棵进程树（排除 `--type=` 与 `--expose-internals`）。
- 敏感信息（账号、密钥、令牌）**不写入记录**，只记形态（如 `sk-gw-…`）。

## 6. 状态标记

| 标记 | 含义 |
| --- | --- |
| ✅ 已确认 | 你确认过的产品特性 |
| 🟡 待确认 | 我观察到但还没经你确认 |
| ❓ 疑问 | 需要澄清 |
| ⚠️ 问题 | 疑似缺陷 / 阻塞 |
