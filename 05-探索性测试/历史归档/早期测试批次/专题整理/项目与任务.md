# 项目与任务：状态能力及历史修正

侧栏既有项目树中的会话，也有最近与置顶入口；后续观察中分别使用 treeitem 与 button。菜单相近不代表可用同一组定位器。来源：[早期产品观察](../%E6%97%A9%E6%9C%9F%E6%8E%A2%E7%B4%A2_%E5%8E%9F%E6%A0%B9%E7%9B%AE%E5%BD%95/01-product-info.md)；[换包后产品观察](../20260929_2153/01-%E4%BA%A7%E5%93%81%E4%BF%A1%E6%81%AF.md)。

| 行为 | 历史可确认范围 | 阅读修正或限制 |
|---|---|---|
| 置顶、重命名 | 后续产品记录有实测 | 只支持该批次行为，不作当前版本保证 |
| 双击入口 | 后续记录有验证 | 阅读具体上下文，不扩大到全部列表 |
| 归档 | 后续看到“已归档聊天 查看 撤销”，且验证查看/撤销 | 早期“缺提示”未完成即时取证；不能继续当已确认缺陷 |
| 未读 | 后续观察未读点，打开后清除 | 缺少手动清除入口的原报告与自动清除行为分开 |
| 分享 | 早期 3/3 无可见结果，后续有对应问题记录 | 未挂 IPC 不能排除主进程静默动作；表述为无可见反馈/未见预期结果 |
| 排序 | 后续记录排序覆盖手动顺序问题 D-05 | 保留具体触发条件与原证据，不抽象成所有排序失败 |
| 拖拽 | 合成事件无效 | 未等价于真实用户拖拽失败 |
| 新建项目 | 原生目录选择相关操作覆盖有限 | 不以已有项目测试代替创建链路 |

来源：[早期任务缺陷记录](../%E6%97%A9%E6%9C%9F%E6%8E%A2%E7%B4%A2_%E5%8E%9F%E6%A0%B9%E7%9B%AE%E5%BD%95/13-%E4%BB%BB%E5%8A%A1%E5%88%97%E8%A1%A8-%E7%BC%BA%E9%99%B7%E8%AE%B0%E5%BD%95.md)；[后续产品观察及对应缺陷导航](../20260929_2153/01-%E4%BA%A7%E5%93%81%E4%BF%A1%E6%81%AF.md)；[后续缺陷报告](../20260929_2153/03-%E7%BC%BA%E9%99%B7%E6%8A%A5%E5%91%8A.md)。
