# 18 项队列与本轮补强

基础判据全部来自 [测试设计](../../04-测试项/记忆与进化功能测试/测试设计.md)，下表补充执行条件，不替代或删减设计断言。可以共享场景和证据，分别登记子检查点。

| 顺序/场景 | case | 本轮必须完成的具体工作 |
|---|---|---|
| 接入与备份 | MEM-01 | 核验包/工具库身份、文件存在与空值、设置和数据归属；备份完整初值、原本不存在文件清单 |
| 面板样本 | MEM-02 | 调主库添加唯一条目并显式选类型；编辑自建内容，独立回读旧/新内容及对应审计 |
| 面板口径 | MEM-05 | 复用 MEM-02/03 样本，对账面板、索引、文件、元数据；分别列各指标定义 |
| 外部修改 | MEM-04 | 分别对 USER.md、AGENTS.md 准备同条件样本；每个文件保留修改前字节、既有备份/审计基线、修改方式、等待条件、宿主感知与新增备份。没有备份承诺时只记录观察 |
| 真实工具 | MEM-03 | 经模型真实工具写入画像/长期内容，读取工具实参/返回与文件、审计；actor=tool 不归为自动沉淀 |
| 召回对照 | MEM-08 | 已索引/未索引/不存在标记对照；查真实召回记录、源文件和行号；提问不泄露待验证答案 |
| 分层注入 | MEM-06 | 准备非空 SOUL/AGENTS/USER/MEMORY/日志，每轮只变一层，与无标记新会话对照；优先实际宿主上下文。仅模型复述不能证明注入缺失，宿主读取缺能力可补留存函数 |
| 注入结构 | MEM-07 | 普通/critical/日志/反思样本，在已确认预算下观察段落顺序/截断；先记录规则来源和统计单位，不凭猜测判失败 |
| 开关保存 | MEM-16 | 每项初值→单项改动→保存反馈→重开回读→机制效果→恢复；复核保存错误原文。保存失败后不要拿未生效开关做开/关对照 |
| 自动沉淀 | MEM-09 | 先结束旧会话并采集落盘基线，再新会话发送独有 AUTO 标记；避免主动记忆工具写入，核查工具轨迹。依据本轮会话ID/标记/审计绑定产物；上一会话日志增量不能证明本轮触发。记录请求/回复实际长度与门槛单位 |
| 频控 | MEM-10 | 第一次满足条件并成功触发→窗口内同等条件再次触发→窗口外再次触发；记录原始时间/标记/产物。只读取两次不算重复触发；第一次未成功则频控效果未验证 |
| 过滤 | MEM-11 | 普通噪音/重复/有效偏好/纯测试敏感标记各一组，经真正自动路径；冻结过滤预期，确认过滤参与，工具直接写入不能替代 |
| 反思 | MEM-12 | 先满足实际触发条件，采前后状态/调用/审计/新反思文件；分别判断触发、状态推进、实质产物。只读历史反思状态记未验证，报告与JSON统一 |
| 晋升 | MEM-13 | 构造有来源的跨日重复、高重要度及普通对照；满足规则后触发反思，读取长期层/元数据/审计和后续注入。人工夹具不算实际历史产物 |
| 蒸馏 | MEM-14 | 隔离样本达到当前已确认阈值，验证真实蒸馏事件、前后内容/归档、重要信息保留及召回；提前安排，不能以“需要样本”不尝试准备 |
| 预算 | MEM-15 | 分别构造刚低于/达到/超过当前有效预算的样本；单位和范围先确认，观察实际链路效果及重要内容处理 |
| 条件入口 | MEM-17 | 仅本轮夹具及可处理确认的非原生路径；无原生能力不触发删除，登记受限步骤和补测条件；导入/导出/清空分别记入口和实际覆盖 |
| 完整恢复 | MEM-18 | 停止触发，全部触及对象逐项恢复并回读hash/设置；新文件与审计增量单列，核对本轮后续会话影响 |

时间窗等待可与不污染其场景的入口/取证交错。同一 UI 串行操作，运行中的调用等完成再继续。准备阶段即写出各场景样本、有效阈值、预期、等待期限与恢复；缺能力按 README 查找后补函数，不跳过整个机制。

对照时使用 [上一轮审核](../2026-10-07-PC88分支审核/同版本结果对照.md)：对象/初值/触发条件不同记不可比，不自行写“修复/退化”。旧结果和本轮结果分开保留。
