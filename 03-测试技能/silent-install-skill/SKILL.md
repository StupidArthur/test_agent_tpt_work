# 静默安装

输入为已下载的安装包、目标版本和明确的安装/升级范围。发布渠道可以是正式版、beta或nightly，不影响按安装器契约选择静默参数。

需要先获取安装包时，使用 [get-latest-package-skill](../get-latest-package-skill/SKILL.md)。本技能不负责选最新包、定时调度或业务回归。

## 执行入口

1. 核对本地安装包路径、来源和校验结果，确认目标产品、版本、架构及安装器类型。计算出的SHA-256只是文件标识，有可信预期值才能据此判断一致性。
2. 明确首次安装还是覆盖升级，绑定目标安装记录及实际安装路径。需要关闭应用时确认该实例已交付安装任务；用户正在使用时不关闭或升级。
3. 按产品说明备份需要保留的数据，记录备份范围、结果及恢复位置。旧备份仅凭日期相同不能当作本轮备份成功。
4. 只读取对应产品/安装器说明。当前支持说明：[TPT Work Windows NSIS](references/tpt-work-windows.md)。其他安装器参数不套用本例，缺契约则记录待补。
5. 单次运行静默安装，保存实际参数、包SHA、进程身份、退出码和日志。有运行中的安装任务时不并发启动；失败先核对实际安装状态，保留原attempt。
6. 分别核验安装器退出结果、目标注册信息、实际可执行文件及版本。启动检查仅在任务要求时按产品接入技能执行；窗口出现不代表业务回归通过。

## 结果与边界

交付包身份、安装前后版本与路径、备份结果、安装日志、退出码、各核验结果及残留。失败或缺条件区分为失败/未验证，不以重试成功覆盖首次异常。

卸载、删除应用数据、清理目录和终止其他任务的进程不是静默安装的默认步骤。安装后的登录、模型凭据和功能测试交给相应测试任务。

本技能由历史nightly流程拆分整理；本轮仅改文档，没有安装测试。产品特定参数的历史适用范围见参考页，原材料保存在 `references/original-nightly-sop.txt`，用于溯源，不作为执行入口。
