## 文档职责

- 通用探索性测试技能：当前执行、记录、推进和补测规则的入口。
- TPT Work 接入技能：专属产品的启动、连接、界面和 API 操作通道。
- 工具文档：当前可调用函数与参数入口，不用复制长指南里的点击代码替代现成函数。
- 接入指南：环境与通道说明；详细实操指南保留启动命令、API 示例和配套测试工程的说明。
- 分层设计：设计背景和示例布局，不是每次执行要读的清单；实际接口以主库 catalog 为准。

探索产出进入 [待审核区](../05-探索性测试/README.md)，审核后再归纳正式方法。历史任务里的草案和 RULES 保留其原范围。
